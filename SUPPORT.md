# Getting Support for Toi Yêu Yuri Online Judge (tyyoj)

Welcome to the `tyyoj` support guide.

## Where to Get Help

- **Documentation:** Review the documentation in `docs/` across our repositories:
  - Architecture overview: `docs/architecture.md`
  - Developer setup: `docs/dev-setup.md`
  - Architecture Decision Records: `docs/decisions/`
- **Bug Reports:** If you encountered unexpected behavior or a bug, please open a bug report using our GitHub Issue template.
- **Feature Requests:** Submit ideas and enhancement proposals through our feature request issue template.
- **Questions & Discussions:** For general questions regarding setup, problem formatting (Markdown + KaTeX math), or custom testlib.h checkers, please open an issue with the `question` template or participate in GitHub Discussions.
